HARNESS
1. Per-test sandbox: one container per (repo, sha), Python 3.11 (fall back to 3.8/3.9 only when python_requires demands it, logged). Install from requirements*.txt, else setup.py/setup.cfg/Pipfile. Store a pip-freeze hash in every cert.
2. Rootdir discovery from pytest.ini/setup.cfg/pyproject.toml/tox.ini. Store both the IDoFT id and the resolved node id (F23 resolves under tests/).
3. Network off (unshare/firewall). A test that needs a live service is swapped under the rule below, never faked.
4. Baseline first: 100 plain reruns per main test -> ledger/baseline/<id>.log. This is the denominator for any speedup.
5. Controlled sources (m), each a separate logged knob: test order, random/numpy seeds, PYTHONHASHSEED, time-freeze offset, tmpdir name; thread/asyncio scheduling where present. Budget: 500 runs per test.
6. Certificate certs/<id>.json: {id, project, sha, pytest_id, node_id, image_digest, pip_freeze_sha, flakecert_version, sources[], m, k, d, schedule[], seed, expected_failure{exc, sig=sha256(normalized traceback)}, bound{per_run_lower:"p/q", formula}}. Valid only on a 3/3 replay with the same sig.
7. Bound check: recompute every bound with fractions.Fraction; compare with empirical runs-to-failure.
8. Blind comparator: a separate process gets only the cert JSON and must reproduce the failure. Record pass/fail per cert.

AUTO-SWAP RULE
Allowed only for: install failure after 2 attempts, a required live network/service/credential, or a non-Linux-only test. Promote the next reserve in frozen order and append a row (reason, log path, sha256). A reserve that fails the same check is retired with a row. Never swap for "hard to reproduce", which is a result.

MAKE TARGETS
make freeze      fetch IDoFT at the pinned commit, check both sha256s, write baseline/HASHES, make baseline/ read-only
make envs        build an image per effective main test; record digests in baseline/HASHES
make baseline    100 plain reruns per main test -> ledger/baseline/*.log, results.csv (method=baseline)
make flakecert   controlled search, budget 500 -> certs/*.json, results.csv (method=flakecert)
make comparator  blind replay per cert -> evidence/comparator.csv
make ledger      ledger/SUMMARY.md: per test, per category (never pooled): baseline rate, controlled rate, ratio, 95% CI, max certified d
make verify      (a) frozen-set sha matches; (b) effective set derived from frozen-set + swaps.csv diffs clean against effective-set.txt; (c) every swap row's evidence file exists and its sha matches; (d) resolve-check and deps-preflight re-run and match; (e) every cert replays 3/3, same sig; (f) every Fraction bound recomputes; (g) every ledger row has an existing log; (h) comparator result present for every cert; (i) README numbers are a subset of SUMMARY.md. Non-zero exit on any miss. Writes evidence/verify.log + evidence/verify-report.json.
CI: make freeze && make verify on every push; heavy targets (envs, baseline, flakecert, comparator) via workflow_dispatch, uploading ledger/, certs/, evidence/.
